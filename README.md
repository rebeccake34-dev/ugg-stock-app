# UGG 货位助手 · Stock Finder

给店铺员工用的手机网页工具：找鞋子放在哪、每天的工作清单、清点、库存变动、退货和 layby 客人。支持中文 / English 切换。

网页地址（开启 GitHub Pages 后）：**https://rebeccake34-dev.github.io/ugg-stock-app/**

> 同一套功能也有 Claude 版本（数据存在 Claude 云端，手机和电脑自动同步）。这个 GitHub 网页版的数据**只存在打开它的那台设备的浏览器里**。

## 功能

| 页面 | 能做什么 |
|---|---|
| 📋 今日 | 每天的工作清单：早小票拍照、店铺/仓库照片、清点 6–8 款（自动推荐最久没点的款）、打扫、整理仓库；周一三五收货 → 导入到货单 → 通知 layby → 展示新品 → 打价格标签；周一订文具，周三订购物袋。记录谁几点完成，照片按日期保存 |
| 🔍 查找 | 输入部分款号或英文名马上找到位置和库存；**批量定位**：一次输入多个货号，在仓库和店面地图上同时标出来，并可一键开始清点 |
| 🗺️ 货位 | 仓库地图（每个货架画成层 × 格，款号直接写在格子里）和店面地图。可**缩放**（按钮或两指捏合），可拖动、改大小、旋转、加文字、**增减货架 / 格 / 层 / 展位**；整理建议（超容量、没货位、卖完占位、可合并） |
| ✅ 清点 | 按货架 / 展位 / 自选款号清点，自动对比系统数，复制差异报告 |
| 📦 库存 | 四种库存变动：① 新到货 ② 卖出 / 顾客退货 / 换货 ③ 退回仓库 ④ 瑕疵品；**一键导入到货单 / 退货单**（Excel、CSV 或粘贴），可撤销；待退清单；Layby 客人；导入 Vend 报表 |
| ☰ 更多 | 库存总览、修改记录、设置、备份 / 恢复 |

容量规则：每格 6 高 × 7 长 × 2 宽 = 84 个大鞋盒；15901 / 15902 特大鞋盒每格只能 5 高 × 1 宽（可在「整理建议」里修改）。

## 开启网页（只需做一次）

1. 打开 https://github.com/rebeccake34-dev/ugg-stock-app/settings/pages
2. **Source** 选 **Deploy from a branch**
3. **Branch** 选 **main**，文件夹选 **/ (root)**，点 **Save**
4. 等 1–3 分钟，打开上面的网页地址；手机浏览器菜单里选「添加到主屏幕」

## 数据与备份

- 数据存在当前设备的浏览器里（localStorage），不同手机之间不会同步。
- 换手机：「更多 → 下载完整备份」→ 在新设备「更多 → 从备份恢复」。
- 照片会压缩后保存，但浏览器空间有限（约 5MB），请定期删除旧照片。

## 文件结构

```
index.html            页面
app.js                全部功能（在 Claude 里用 Claude 数据库，在普通浏览器里用本机存储）
i18n.js               英文翻译
styles.css            样式
data/seed.js          初始货位和库存（由 tools/convert.py 从 Word 货位表 + Vend 报表生成）
vendor/xlsx.full.min.js   读取 Excel 的开源组件（SheetJS）
sw.js, manifest.webmanifest, icon.svg   离线使用 / 添加到主屏幕
tools/convert.py      Word 货位表 + Vend 报表 → data/seed.js
```
