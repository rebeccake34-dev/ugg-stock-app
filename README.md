# UGG 货位助手 · Stock Finder

一个给店铺员工用的手机网页小工具：**输入款号就能看到鞋子放在哪里**，顺便做每日清点和退库登记，所有修改都会记录是谁改的。

打开地址（开启 GitHub Pages 后）：**https://rebeccake34-dev.github.io/ugg-stock-app/**

## 功能

| 页面 | 能做什么 |
|---|---|
| 🔍 查找 | 输入款号的一部分（如 `3108`、`AS2115`）或英文名（如 `Tay`），马上显示：系统库存、待退库数量、在店面/库房的哪个位置 |
| 🗺️ 货位 | 库房 6 个货架按原来的表格画成格子图；店面 41 个展位。点格子可以 **添加 / 移动 / 删除 / 改备注**，自动记录操作人和时间。可以给货架改名，也可以新增位置。还能一键 **打印货位表**（表格 8 号字、标题 10 号字） |
| ✅ 清点 | 选一个货架/展位/全部 → 逐个款号填实数 → 自动和 Vend 系统数对比 → 一键复制差异报告发给经理，或下载 CSV |
| 📦 退库 | 登记款号、尺码、数量、原因 → 待退清单 → 寄出后标记「已寄出」→ 复制清单或下载 CSV |
| ☰ 更多 | 库存总览（库存偏低 / 有货没登记货位 / 卖完了）、导入最新 Vend 报表、修改记录、备份与恢复、设置名字 |

## 每天怎么用（SOP）

1. **第一次打开**：点右上角填自己的名字。手机浏览器菜单里选「添加到主屏幕」，以后像 App 一样打开。
2. **开店前 / 每周一**：在 Vend 后台导出库存报表（和这次用的 `vend-inventory_period_end_count…xlsx` 同一种），在「更多 → 导入 Vend 库存」选择文件。
3. **找鞋**：「查找」输入款号 → 点位置标签 → 看到格子图里高亮的位置。
4. **移动了库存**：在「货位」点那一格 → 「移动」→ 选新位置。不用再去改 Word 表格。
5. **每日清点**：「清点」→ 选范围 → 填数 → 完成 → 复制报告。
6. **退库**：「退库」→ 登记 → 寄出后点「已寄出」，并在 Vend 里做库存调整。
7. **每周五**：「更多 → 下载备份」，存到自己的邮箱或网盘。

## 重要说明

- **数据存在各自手机的浏览器里**，不会自动同步到同事的手机。要让同事用同一份货位表：在你的手机「下载备份」→ 发给同事 → 同事在「从备份恢复」。
- 这个网页是公开的（任何人知道地址都能打开**初始货位表**），但大家的修改、清点和退库记录只存在自己的设备上，别人看不到。
- 不需要网络也能用（第一次打开之后）。

## 文件结构

```
index.html            页面
app.js                全部功能
styles.css            样式
data/seed.js          初始数据（由下面的脚本从 Word 货位表 + Vend 报表生成）
vendor/xlsx.full.min.js   读取 Excel 的开源组件（SheetJS）
sw.js, manifest.webmanifest, icon.svg   离线使用 / 添加到主屏幕
tools/convert.py      把 Word 货位表和 Vend 报表转换成 data/seed.js
```

### 重新生成初始数据（一般不需要）

```bash
pip install python-docx openpyxl lxml
python3 tools/convert.py STORE_STOCK_LOCATION.docx STOREROOM_LOCATION.docx vend-export.xlsx data/seed.js
```
